# Rediseño de Formularios Corporativos

Proyecto de rediseño y modernización visual de formularios corporativos, desarrollado a partir de documentos existentes y orientado a mejorar su legibilidad, jerarquía visual, organización de la información y experiencia de uso.

El proyecto presenta tres formularios en sus versiones **original** y **rediseñada**, permitiendo comparar directamente la estructura documental existente con la propuesta de modernización visual.

## 🚀 Demo

La propuesta visual y los casos de estudio pueden consultarse en la versión desplegada del proyecto:

**[Ver proyecto en Vercel](https://rediseno-formularios.vercel.app/)**

---

## 📌 Sobre el proyecto

Los formularios corporativos suelen contener una gran cantidad de información organizada en tablas, campos, resultados y secciones administrativas. Cuando estos documentos mantienen estructuras visuales tradicionales durante largos periodos, pueden presentar problemas relacionados con:

- Jerarquía visual limitada.
- Lectura poco fluida.
- Exceso de elementos visuales.
- Organización poco clara de la información.
- Falta de consistencia entre diferentes formularios.
- Dificultad para identificar rápidamente las secciones principales.

Este proyecto plantea una propuesta de rediseño enfocada en conservar la estructura y contenido funcional de los documentos, mientras se mejora su presentación visual.

El resultado busca demostrar cómo un documento corporativo existente puede evolucionar hacia una interfaz documental más clara, consistente y adecuada para entornos digitales.

---

## 🎯 Objetivos

- Analizar la estructura visual de formularios corporativos existentes.
- Mantener la información y estructura funcional de los documentos.
- Mejorar la jerarquía visual de títulos, secciones y contenidos.
- Facilitar la lectura y localización de información.
- Crear una identidad visual consistente entre los diferentes formularios.
- Comparar visualmente las versiones originales y rediseñadas.
- Documentar el código HTML de cada formulario.

## 🎨 Original vs. Rediseño

Cada formulario contiene dos versiones:

| Archivo         | Descripción                                             |
| --------------- | ------------------------------------------------------- |
| `original.html` | Versión basada en la estructura original del formulario |
| `redesign.html` | Propuesta de rediseño visual                            |

El rediseño mantiene la información principal del documento y trabaja sobre aspectos como:

- Jerarquía visual.
- Tipografía.
- Espaciado.
- Organización de secciones.
- Consistencia visual.
- Presentación de tablas.
- Diferenciación entre encabezados y contenido.
- Legibilidad.
- Distribución de la información.

La comparación entre ambas versiones forma parte del caso de estudio presentado en la aplicación web.

## 💡 Proceso de trabajo

El desarrollo del proyecto se realizó siguiendo un proceso de transformación progresiva:

## 1. Análisis

Revisión de la estructura existente de los formularios, identificando:

- Secciones.
- Campos.
- Tablas.
- Jerarquías.
- Elementos gráficos.
- Información repetitiva.
- Distribución del contenido.

## 2. Conservación de la estructura funcional

Se mantuvieron los contenidos y campos principales de cada documento para que el rediseño no alterara el propósito funcional del formulario.

## 3. Rediseño visual

Se trabajó sobre:

- Jerarquía de información.
- Tipografía.
- Espaciado.
- Encabezados.
- Tablas.
- Separación de secciones.
- Consistencia gráfica.
- Presentación de resultados.

## 4. Comparación

Se conservaron las versiones originales y rediseñadas para facilitar la comparación visual y documentar el proceso de transformación.

## 5. Presentación web

Finalmente, los formularios y sus casos de estudio fueron integrados en una aplicación web desarrollada con React y Vite.
